# Roue des Tâches

Outil de tirage au sort pondéré pour l'attribution de tâches au sein de l'équipe Digitalizers — réalisé dans le cadre du cas pratique **Mentor Citizen Developer**.

Ce projet évalue le processus de *vibe coding* (prompt → résultat), pas la perfection du produit final.

### Stack

- Angular 21 (standalone, signals)
- localStorage pour la persistance
- Canvas pour la roue animée
- Design System Digitalizers (Quicksand + Vidaloka, cyan `#18ffff`)
- Responsive desktop / tablet / mobile
